# NOVA ONE

외부 3D 모델 없이 Three.js 코드로 만든 가상 헤드폰 출시 페이지. 정적 파일만으로 동작하며 실제 주문, 결제, 계정, 개인정보 수집 기능은 없습니다.

## 로컬 실행

Node.js 22 이상에서 `npm start` 실행 후 http://localhost:4173 에 접속하세요. 런타임 라이브러리가 `dist/vendor`에 포함되어 있어 실행 시 npm 설치나 외부 CDN 연결이 필요하지 않습니다. `npm run check`로 JavaScript 구문을 검증합니다. `npm run build`는 앱·모델·스타일의 내용 해시를 URL에 붙여 배포 후 이전 파일이 브라우저 캐시에 남는 것을 방지합니다. GitHub Actions에서도 자동 실행합니다.

## 구성

- `dist/headphones.js`: 코드로 작성한 헤드밴드, 쿠션, 요크, 하우징, 다이얼, 포트, 로고. `createHeadphones()`가 `{group, setColor(hex)}`를 반환합니다. 나중에 GLB 로더로 이 어댑터를 교체할 수 있습니다.
- `dist/app.js`: 스크롤 장면, 조명, 컬러, 회전, 디테일 탭, 배터리 카운트, 구매 시연. 모든 장면은 하나의 모델 인스턴스를 공유합니다.
- `dist/style.css`: 반응형 레이아웃, 컬러 테마, 움직임 줄이기 지원.
- `dist/fallback.svg`: WebGL 실패 시 직접 제작한 정적 대체 일러스트.
- `.github/workflows/pages.yml`: main 푸시 시 dist를 GitHub Pages에 배포합니다. 저장소 Pages 설정의 Source는 GitHub Actions입니다.

## 확인할 인터랙션

첫 화면의 짧은 회전과 부유, 자연스러운 세로 스크롤, 몰입 모드 토글, 디테일 탭, 배터리 숫자, 세 가지 컬러, 컬러 스튜디오의 드래그 및 키보드 슬라이더, 정면·측면·후면 버튼, 기본 각도 복원, 선택 색상을 반영하는 구매 시연 창. 창은 닫기·계속 둘러보기·Escape로 닫을 수 있습니다.

## 라이선스와 제한

Three.js 0.180.0 및 RoomEnvironment는 MIT 라이선스로 제공되며 라이선스 사본은 `dist/vendor/THREE-LICENSE.txt`에 있습니다. 제품 모델, 로고, 대체 일러스트는 이 프로젝트에서 코드로 제작했습니다. 외부 사진, 구매한 모델, 외부 웹폰트는 사용하지 않습니다. 설치된 시스템 글꼴을 사용합니다.

모델은 실제 제조용 CAD가 아닌 시각화용 외형입니다. ANC 체험은 시각 효과이며 실제 오디오 처리를 하지 않습니다. 가격·사양·브랜드는 모두 가상입니다. WebGL2 미지원 또는 그래픽 컨텍스트 손실 시 정적 일러스트로 전환합니다. 저성능 모바일에서는 픽셀 비율과 프레임 빈도를 제한하지만 기기별 성능 차이가 있습니다.
